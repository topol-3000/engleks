# Access Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Invite-only signup, user status, a per-minute rate limit and a daily token budget enforced in `process_text`, an `engleks-admin` CLI, and the bot's `/start <code>`.

**Architecture:** New domain module `domain/access.py` holds the access types and exceptions; three new ports (`InviteRepository`, `UsageLedger`, `UserAdminRepository`) get SQL adapters in `infra/db/repositories.py`. `authenticate` stops creating users; `redeem_invite` is the only way in. `cli.py` is a second composition root over the same use cases. Each task leaves `make lint && make test` green.

**Tech Stack:** Python 3.14, uv workspace, FastAPI, SQLAlchemy 2 async + Alembic, Postgres 18, Typer (new), aiogram 3, pydantic, pytest + testcontainers.

**Spec:** [docs/superpowers/specs/2026-11-03-access-design.md](../specs/2026-11-03-access-design.md)

## Global Constraints

- Follow AGENTS.md: layer rules, `structlog` event names in snake_case, never log the user's text, the LLM's output or **an invite code**; log ids, counts, reasons.
- Migration `0001` stays byte-for-byte; all schema changes go in `0002_access` (revision id `"0002"`, `down_revision = "0001"`).
- Codes: 12 characters from `ABCDEFGHJKMNPQRSTUVWXYZ23456789`, generated with `secrets`; input uppercased before every lookup (redeem and revoke).
- Config (`API_` prefix): `rate_limit_per_minute = 10`, `daily_token_budget = 200000`, `bot_username: str | None = None`.
- The database's clock is the only clock for limits and expiry: `now()`, `date_trunc('minute', now())`, `(now() AT TIME ZONE 'UTC')::date`. No `datetime.now()` in use cases or adapters.
- Contract changes are additive only (new `ErrorCode`s and DTOs). The only changed meaning is `POST /v1/texts/process` for an unknown identity → `401 invite_required` (owner-approved).
- Typer is the one new runtime dependency (owner-approved): `uv add --package engleks-api typer`. Import-linter changes are the two in Task 6, nothing else.
- Commit messages: conventional style as in `git log`, ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

- A user types the code by hand in lowercase (`/start abcd2345wxyz`): it registers, because the API uppercases before lookup. Pinned in Task 4 (`test_lowercase_code_is_accepted`, unit and HTTP).
- An override of `0` (`daily_token_budget = 0`) must apply, not fall back to the default: overrides are applied with `is not None`, never truthiness. Pinned in Task 3 (`test_zero_override_is_applied`).
- `/start` followed by more than 64 characters: the bot answers the invalid-invite message without calling the API (the request DTO rejects it), and `/help anything` never redeems. Pinned in Task 7 (`test_start_with_overlong_code`, `test_help_with_args_does_not_redeem`).
- `set-limits ID --per-minute 5` on a user who already has a daily override keeps that daily override. Pinned in Task 6 (`test_set_limits_keeps_the_other_override`).
- A registered user with no requests today still shows in `user list`, with `0` requests and `0` tokens (left join on today's `usage_daily`). Pinned in Task 6 (`test_user_list_shows_user_without_usage`).
